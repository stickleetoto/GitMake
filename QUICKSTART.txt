GitMake v1.2.9 - QUICK START

INSTALL
1. Extract GitMake_v1.2.9_Windows_x64.zip.
2. Run GitMake-Setup.exe.
3. GitMake checks Git, GitHub CLI/login, and optionally connects Claude Code MCP.

EVERYDAY CLI
  cd MyProject
  gitmake

ZIP INPUT
  gitmake Project.zip

CLAUDE / MCP
  gitmake ai setup --write
  Ask Claude: "이 프로젝트 GitHub에 올려줘"
  Claude should call gitmake_publish.
  GitMake prepares the reviewed plan and opens the client-controlled approval UI.
  After human approval, GitMake revalidates and applies the exact plan inside the same interactive publish operation.

FALLBACK WHEN MCP ELICITATION IS UNAVAILABLE
  gitmake_prepare
  Review the plan, then in a terminal run:
    gitmake approve
  Claude calls gitmake_apply with the reviewed plan ID.

DESTRUCTIVE PLAN
  MCP approval requires the plan-specific DELETE-XXXXXX phrase.
  Terminal fallback:
    gitmake approve --destructive

UPGRADE
  gitmake upgrade

  Coming from v1.2.5 or earlier? Self-upgrade never ran in those builds.
  Install once from this package instead:
    .\gitmake.exe install        (Windows)
    ./gitmake install            (Linux / macOS)
  Then check: gitmake --version

EXPERT COMMANDS
  gitmake help --expert
