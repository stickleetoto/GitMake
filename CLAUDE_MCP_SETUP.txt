GitMake v1.0.0 + AI/MCP

ONE-CLICK CLAUDE SETUP
  gitmake ai setup

Enable reviewed write/apply tools:
  gitmake ai setup --write

Status:
  gitmake ai status

NORMAL AI WORKFLOW
1. Ask Claude to publish or prepare the current project folder/ZIP.
2. Claude should prefer the high-level `gitmake_prepare` MCP tool.
3. Claude shows the reviewed plan, provenance, changes, and risk.
4. Human runs:
     gitmake approve
5. Human tells Claude approval is complete.
6. Claude calls `gitmake_apply` with only the reviewed plan ID.

There is no approval token to copy/paste in the v1 flow.
The local approval grant is short-lived, single-use, and bound to the exact reviewed plan.

Destructive plan:
  gitmake approve --destructive

Read-only MCP remains the default. GitMake never exposes a tool that can create its own human approval grant.

Generic MCP descriptor:
  gitmake ai setup --client generic --json
