GitMake v1.0.0 - QUICK START

INSTALL
1. Extract GitMake_v1.0.0_Windows_x64.zip.
2. Run GitMake-Setup.exe.
3. GitMake checks Git, GitHub CLI/login, and optionally connects Claude Code MCP.

EVERYDAY CLI
  cd MyProject
  gitmake

ZIP INPUT
  gitmake Project.zip

CLAUDE / MCP
  gitmake ai setup --write
  Ask Claude: "이 프로젝트 GitHub에 올려줘"
  Review the plan.
  In your terminal run:
    gitmake approve
  Return to Claude and say approval is complete.
  Claude calls gitmake_apply with the plan ID. No approval token copy/paste is needed.

DESTRUCTIVE PLAN
  gitmake approve --destructive
  Then type the DELETE-XXXXXX confirmation shown by GitMake.

UPGRADE
  gitmake upgrade

EXPERT COMMANDS
  gitmake help --expert
