GitMake v0.6.1 - QUICK START

INSTALL (recommended)
1. Unzip the Windows x64 package.
2. Double-click GitMake-Setup.exe.
3. If Claude Code is installed, Setup connects GitMake MCP automatically in read-only mode.
4. Open a new PowerShell window.
5. Run:
     gitmake doctor
     gitmake ai status

ONE-COMMAND CLAUDE SETUP
  gitmake ai setup

Enable reviewed AI write tools only when you want them:
  gitmake ai setup --write

Check or remove the integration:
  gitmake ai status
  gitmake ai remove

FIRST PROJECT
1. Put the project ZIP in a folder.
2. Open PowerShell in that folder.
3. Run: gitmake init
4. Run: gitmake

AI / AGENT FLOW
  gitmake ai describe --json
  gitmake --dry-run --read-only --json
  gitmake plan --json
  gitmake apply <plan_id> --json   (after approval)

RAW MCP (advanced / non-Claude clients)
  gitmake mcp
  gitmake mcp --allow-write
