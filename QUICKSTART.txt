GitMake v0.7.1 - QUICK START
============================

WINDOWS
1. Extract GitMake_v0.7.1_Windows_x64.zip.
2. Double-click GitMake-Setup.exe.
3. Open a new PowerShell window.
4. Run: gitmake doctor
5. If Claude Code is installed, Setup connects read-only MCP automatically.

LINUX / macOS
1. Extract the package for your platform.
2. Run: ./gitmake install
3. Open a new shell if PATH was updated.
4. Run: gitmake doctor

PROJECT
1. Put the project source ZIP in a folder.
2. Run: gitmake init
3. Review gitmake.json.
4. Preview safely: gitmake --dry-run --read-only --json
5. Publish: gitmake

SAFER AI FLOW
1. gitmake plan --json
2. Review the plan.
3. For local human CLI apply: gitmake apply <plan_id>
4. For MCP/AI apply, the human runs: gitmake approve <plan_id>
5. Give the one-shot token only to the reviewed apply call.

AI / MCP
Claude Code one-click:
  gitmake ai setup

Generic MCP descriptor:
  gitmake ai setup --client generic --json

Status:
  gitmake ai status

SECURITY DEFAULTS
- managed sync preserves remote-only files
- .github/** and .gitmake/** protected
- likely secrets block publish
- large direct-Git files block unless safely handled by LFS
- required-PR protected branches are not bypassed
- no force push / repo delete / history rewrite
