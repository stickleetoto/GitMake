GitMake v0.5.0 - QUICK START

INSTALL
1. Unzip the Windows x64 package.
2. Double-click GitMake-Setup.exe.
3. Open a new PowerShell window.
4. Run: gitmake doctor

FIRST PROJECT SETUP
1. Put your project ZIP in a folder.
2. Open PowerShell in that folder.
3. Run: gitmake init
4. Accept/edit the suggested repository settings.
5. Run: gitmake

FAST PATH
With one ZIP and no config, plain `gitmake` can auto-create a private config and publish immediately.

DAILY USE
  gitmake

AI / AGENT USE
  gitmake ai describe --json
  gitmake ai install
  gitmake doctor --json
  gitmake --dry-run --read-only --json
  gitmake --json

USEFUL COMMANDS
  gitmake init
  gitmake init --yes
  gitmake --dry-run
  gitmake doctor
  gitmake upgrade
  gitmake --version
