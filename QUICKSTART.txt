GitMake v0.3.1 - QUICK START
============================

INSTALL (Windows)
1. Run GitMake-Setup.exe.
2. Open a NEW PowerShell/Terminal window.
3. Run: gitmake doctor

FIRST PROJECT
1. Put one project .zip in a folder.
2. Open a terminal in that folder.
3. Run: gitmake

MULTIPLE ZIP FILES
Run: gitmake YourProject_Source.zip

CONFIG ONLY
Run: gitmake init YourProject.zip

PREVIEW
Run: gitmake --dry-run

SKIP A CONFIGURED RELEASE
Run: gitmake --no-release

UPDATE GITMAKE ITSELF
Run: gitmake upgrade

DEBUG
Run: gitmake doctor
Run: gitmake --verbose

GitMake never force-pushes or deletes repositories.
